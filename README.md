# Grafo Básico en Java

## Descripción
Este proyecto implementa un grafo no dirigido utilizando el lenguaje de programación Java. Permite administrar vértices y aristas mediante un menú interactivo en consola.

## Operaciones básicas
1. Insertar vértice.
2. Insertar arista.
3. Buscar vértice.
4. Mostrar grafo.
5. Eliminar arista.
6. Eliminar vértice.

## Tecnologías utilizadas
- Java 17.
- Apache NetBeans.
- Maven.

## Ejecución
Abrir el proyecto en NetBeans y ejecutar la clase `GrafoBasico`.

## Autoría
Proyecto académico desarrollado para practicar estructuras de datos y operaciones básicas de grafos.
