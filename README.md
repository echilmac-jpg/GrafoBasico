# Grafo Básico en Java

## Descripción
Este proyecto implementa un grafo no dirigido utilizando el lenguaje de programación Java. Permite administrar vértices y aristas mediante un menú interactivo en consola.

## Operaciones básicas
1. Insertar vértice.
2. Insertar arista.
3. Buscar vértice.
4. Mostrar grafo.
5. Eliminar arista.
6. Eliminar vértice.

## Tecnologías utilizadas
- Java 17.
- Apache NetBeans.
- Maven.

## Ejecución

El proyecto fue desarrollado en Apache NetBeans utilizando Java 17. Para ejecutarlo, se abre el proyecto GrafoBasico en NetBeans y se ejecuta la clase principal GrafoBasico.java.

El programa muestra un menú interactivo en consola que permite realizar las operaciones básicas de un grafo.
